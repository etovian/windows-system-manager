# Milestone 3 Design: Automated & Interactive Remediation Engine (`sysmgr fix`)

## Overview & Goals
Milestone 3 equips `sysmgr` with safe, verifiable remediation capabilities. Building upon the advisory findings generated by the diagnostic probes in Milestones 1 and 2, this milestone enables users and autonomous agents to resolve detected anomalies while strictly enforcing safety boundaries, dry-run simulation, and automated rollback plan generation committed to git.

---

## 1. Core Architecture & Lifecycle Pipeline

All remediations are executed via a decoupled `RemediationRunner` through a mandatory 5-stage lifecycle pipeline:

```
           sysmgr fix <action_id> / sysmgr doctor --fix
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────┐
│                    Stage 1: Pre-flight Check                    │
│    - Validate action ID exists in RemediationRegistry           │
│    - Verify Administrator status if requires_admin=True         │
└────────────────────────────────┬────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────┐
│                     Stage 2: Dry-Run Guard                      │
│    - If --dry-run: simulate changes, output planned actions     │
└────────────────────────────────┬────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────┐
│            Stage 3: Rollback Generation & Git Commit            │
│    - If persistent alteration (e.g. services, registry, files): │
│      * Snapshot pre-change baseline state                       │
│      * Write docs/rollback/YYYY-MM-DD-<action>-rollback.md      │
│      * Include manual Safe Mode Command Prompt instructions     │
│      * Commit markdown file to git repository                   │
└────────────────────────────────┬────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────┐
│                     Stage 4: Fix Execution                      │
│    - Execute remediation handler with structured error barrier  │
│    - Record list of changes made (services, files, settings)    │
└────────────────────────────────┬────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────┐
│              Stage 5: Post-Fix Probe Verification               │
│    - Re-run the parent diagnostic probe to confirm resolution   │
│    - Return strongly typed RemediationResult                    │
└─────────────────────────────────────────────────────────────────┘
```

### Core Data Models (`src/sysmgr/remediations/models.py`)
- **`RemediationContext`**: Execution flags (`dry_run: bool`, `auto_confirm: bool`, `elevated: bool`).
- **`RollbackPlan`**: Defines pre-change baseline state, automated reversal commands, and manual Safe Mode instructions.
- **`RemediationResult`**: Contains `success: bool`, `action_id: str`, `changes_made: List[str]`, `rollback_file: Optional[str]`, `error: Optional[str]`, and `post_check: Optional[DiagnosticResult]`.

## 2. Handler Registry & Initial Handlers

### Handler Classification
1. **Transient / Memory Actions (No Git Rollback Needed)**:
   - `flush-dns-cache`: Clears DNS resolver cache via `ipconfig /flushdns`. Post-check: `NetworkAdapterProbe`.
   - `renew-dhcp-lease`: Renews DHCP leases via `ipconfig /renew`. Post-check: `NetworkAdapterProbe`.
2. **Persistent Actions (Mandatory Git Rollback Plan & Safe Mode Guide)**:
   - `start-bluetooth-service`: Starts Windows `bthserv` service (`Start-Service bthserv`). Rollback plan snapshots initial service state and startup type; rollback script stops service and restores startup type. Safe Mode instructions: `sc.exe config bthserv start= demand` & `net stop bthserv`. Post-check: `BluetoothProbe`.
   - `clean-temp-files`: Purges non-locked files older than 24 hours from `%TEMP%`. Rollback plan logs purged file counts and reclaimed MB. Post-check: `DiskSpaceProbe`.
3. **Firmware / Manual Guidance**:
   - `enable-tpm-in-bios`, `enable-secure-boot`: Informational guides with step-by-step UEFI/BIOS instructions and partition style verification (`mbr2gpt`).

## 3. CLI Commands & User Workflows

1. **`sysmgr fix <action_id>`**:
   - Flags: `--dry-run`, `--yes / -y`, `--json`.
   - Resolves action, prompts for confirmation if persistent, generates rollback plan, executes fix, re-checks probe, and outputs Rich summary.
2. **`sysmgr doctor --fix`**:
   - Flags: `--category`, `--timeout`, `--dry-run`, `--yes / -y`.
   - Runs full diagnostic suite, identifies fixable probes, prompts user to select or apply all, executes with safeguards.

## 4. Testing & Safety Simulation

- Subprocess and OS mocking fixtures for Windows commands and service management.
- Unit tests verifying registry lookup, dry-run safety guarantees, rollback markdown formatting & git commit mock, and post-fix probe re-checks.
- CLI end-to-end test suite using Typer's `CliRunner`.
